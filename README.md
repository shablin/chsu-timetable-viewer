# unlinker
An extension for Chromium based browser that can help you block specific links on the 
web pages

## Installation

#### Step 1: Unzip the Extension File
- Locate the downloaded `.zip` file from 
[Releases](https://github.com/shablin/unlinker/releases) - Right-click the file and 
select Extract All (Windows) or Show Package Contents (macOS).

Ensure the extracted folder contains a manifest.json file. This file is required for 
the browser to recognize the extension

#### Step 2: Open the Extensions Page
- Navigate to the browser’s extension management page - Select Extensions > Manage 
Extensions.

#### Step 3: Enable Developer Mode
- On the Extensions page, look for the Developer mode toggle in the top-right corner. 
- Switch it ON.

>[!IMPORTANT] This enables additional options for loading unpacked extensions. It is 
>recommended to turn this off after installation for security.

#### Step 4: Load the Unpacked Extension
- Click the Load unpacked button (usually located in the top-left corner of the 
Extensions page). A file explorer window will open. - Navigate to the unzipped folder 
that contains the manifest.json file. - Select the folder and click Select Folder (or 
Open).

#### Step 5: Verify Installation
The extension should now appear in your list of installed extensions. Check the Status 
to ensure it is enabled. You can pin the extension to your toolbar by clicking the 
puzzle piece icon (Extensions menu) and selecting the extension.
